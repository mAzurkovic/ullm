# ullm

The **ullm** project is a simple, yet fully featured and modern *Large Language Model* (LLM). It includes a *pre-trained* base model and a *fine-tuned* assistant model catered to chat conversations.

## Background and Motivation

The most valuable peice of technical advice, in my opinion, is to "understand the fundamentals". This can be applied to any feild. For example, in my domain of software engineering; all novel technologies, complex design decisions, and projects can be boiled down into basic building blocks like databases, web servers, file systems, etc.

With the prevalence of AI these days, I want to apply this principle to LLMs. **The goal of this project is to build a fully featured LLM assistant from scratch in order to demistify this technology for myself and others.**
